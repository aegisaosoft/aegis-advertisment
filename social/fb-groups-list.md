# Facebook groups for MyEZToll outreach

Collected 2026-09-21 from the groups' public "About" pages (no login). Member counts and activity
are as Facebook showed them that day. Post texts: `reddit-and-fb-groups.md`, section 2.

**Admins:** each group lists its admins and moderators at `<group url>/members/admins`
(visible after joining for private groups). Write to them from the My EZToll page or a personal
profile with the DM in section 2.1/2.2. Admin names are deliberately not copied here.

**Rule that applies almost everywhere:** no self-promotion without admin approval, no "DM me / PM me",
no private messages to members. So: DM the admin first, post only after a yes, answer in comments.

## Spanish-speaking (searched inside Facebook, logged in, 2026-09-21)

**There are no Spanish-language Turo-host groups in the US.** Queries "anfitriones turo", "turo en español",
"turo latinos", "turo hispanos", "renta de autos turo", "alquiler de autos turo negocio" return English Turo
groups, Turkish-series groups, or car rental in **Cuba / Mexico / Colombia / Ecuador** (no US tolls, skip).
"Renta de carros para uber" = Mexico (CDMX, GDL, Tijuana, Juárez), not US. Houston / NY / NJ searches only
return used-car sales and room rentals.

The one US Spanish-language rental group worth the post:

## Not found

- **Spanish-speaking host groups**: none in the US, see above.
- **Independent rental companies / HQ / Fleetwire users**: no active public group found. Better reached
  through ICRA, Auto Rental News and LinkedIn.
- **Rideshare fleet owners** (renting cars to Uber/Lyft drivers): groups exist, but the public ones are
  mostly drivers. Search inside Facebook for "rideshare fleet owners" or "TLC fleet".
